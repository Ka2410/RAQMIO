# Raqmio — موقع الشركة

موقع ثابت (Static) ثنائي اللغة (عربي/English) بدون أي اعتماديات. لا يحتاج PHP ولا قاعدة بيانات.

## الرفع على الاستضافة
1. ارفع **محتويات** مجلد `dist/` (وليس المجلد نفسه) إلى `public_html` (أو جذر الدومين).
2. تأكد أن الملف المخفي `.htaccess` اتنقل معاه (يفعّل HTTPS وصفحة 404 والكاش).
3. أعد البناء بالدومين الحقيقي لتوليد روابط SEO الصحيحة.

## GitHub Pages

المستودع `Ka2410/RAQMIO` ينشر ملفات الموقع الثابتة من جذر فرع `main`. رابط الموقع: `https://ka2410.github.io/RAQMIO/`. عند تحديث الكود، شغّل البناء بإعداد `SITE_URL` و`SITE_BASE=/RAQMIO`، ثم انسخ محتويات `dist/` إلى جذر المستودع وادفع التغييرات إلى `main`. ملفات الصفحات والأصول تدعم مسار GitHub Pages الفرعي.

ملف `site.config.zip` نسخة مضغوطة من الملفات، لذلك لا يُرفع مع مصدر المشروع.

## قبل الإطلاق (مرة واحدة)
عدّل `site.config.mjs` (البريد، حسابات السوشيال إن وجدت) ثم ابنِ بالدومين الحقيقي:

```
SITE_URL=https://your-domain.com npm run build
```

هذا يضيف canonical وOpen Graph وsitemap.xml وrobots.txt بروابط صحيحة.

## الأوامر
- `npm run dev` — معاينة محلية على http://localhost:4173/
- `npm run build` — توليد `dist/`
- `npm run verify` — بناء + فحص الروابط والعناوين وalt وhreflang والأصول

## البنية
- `site.config.mjs` — الهاتف، الواتساب، البريد، الدومين
- `src/copy.mjs` — كل النصوص عربي/إنجليزي
- `src/content.mjs` — الخدمات الست
- `src/render.mjs` — القوالب | `src/styles.css` | `src/site.js`
- `public/` — الشعار والخطوط (مستضافة محليًا، بدون طلبات خارجية) وصورة المشاركة
